# Факапы, fallback и буфер

## Что может сломаться

| Симптом | Причина | Что делать |
|---|---|---|
| Демо не стартует | окружение / модель | fallback: скриншоты + локальные копии |
| Модель отвечает не по формату | длинный промпт | сократить промпт, повторить |
| Нет сети | внешний API | перейти на локальные артефакты |
| Долгий ответ | таймаут модели | переключиться на заготовку |
| Участники не поняли | слишком много теории | перейти к упражнению |

## Fallback-план

- Сохранённые скриншоты прогонов `auto` и `chat`.
- Локальные копии артефактов обеих спецификаций.
- «Сухой» разбор: что должно было получиться и почему.

## Правило

Не чинить демо дольше 2–3 минут при всех. Переключиться на fallback и
разобрать, почему сбой сам по себе показателен.
