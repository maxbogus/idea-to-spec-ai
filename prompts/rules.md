# Система правил (для всех ролей)

## Базовые правила

1. **Факт без источника — не факт.** Помечай «допущение».
2. **Пробел — результат.** Пиши «чего не знаем», а не выдумывай.
3. **Три состояния:** факт / допущение / гипотеза.
4. **Не больше 3 вопросов** за раз; спрашивай только то, что меняет следующий шаг.
5. **Проверяй контур:** B2C / B2B / B2G, Россия / трансгранично, локализация.
6. **Проверяй интеграции:** платёжные, государственные, внешние API.
7. **Проверяй данные:** персональные, минимизация, срок хранения (GDPR by design).
8. **Каждый этап заканчивается чеклистом полноты.**

## Антипаттерны

- «Сделать красиво» без критериев.
- Смешивать бизнес- и системный анализ.
- Выдавать гипотезу о решении за потребность.
- Оставлять критерий приёмки неозвученным.

## Чеклист BA-gate

- [ ] problem statement сформулирован
- [ ] success metric измерим
- [ ] персоны и контур определены
- [ ] домены и тарифы названы
- [ ] ограничения зафиксированы
- [ ] открытые вопросы выписаны

## Чеклист SA-gate

- [ ] use cases описаны
- [ ] функциональные требования перечислены
- [ ] нефункциональные требования перечислены
- [ ] интеграции названы
- [ ] данные и безопасность учтены

## Чеклист Spec-gate

- [ ] спецификация полна
- [ ] traceability matrix заполнена
- [ ] risk register заполнен
- [ ] human oversight plan намечен
