# Skills — повторяемые процедуры

Здесь живут **скилы**: повторяемые процедуры, оформленные как пошаговые
инструкции с проверкой. Скил описывает «как сделать», а не «что решить».

## Формат скила

```markdown
# Skill: <что делает>

## Когда использовать
- …

## Что делать
1. …

## Метрики / проверка
- …
```

## Индекс

| Скил | Назначение | Кто применяет | Приоритет |
|---|---|---|---|
| `collect-sources.md` | Сбор источников с цитированием, «факт без источника — не факт» | BA, PM | P0 |
| `mock-respondents.md` | Модельные персоны с маркировкой синтетики | BA, Designer | P1 |
| `detect-contradictions.md` | Поиск противоречий между требованиями | SA, Architect | P0 |
| `analyze-data.md` | Воспроизводимые расчёты и метрики с базой | PM, SA | P2 |

> Скил добавляется, только если он уменьшает число немаркированных
> допущений. «Больше агентов и скилов» само по себе — не преимущество.
