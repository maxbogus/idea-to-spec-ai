# Предварительная архитектура воркшопа

## 1. Оркестратор

Оркестратор — единая точка входа. Он:

1. спрашивает режим: `auto` / `chat` / `hybrid`;
2. запускает этапы по порядку;
3. проверяет полноту после каждого этапа;
4. задаёт вопросы пользователю (в chat/hybrid);
5. формирует отчёт и складывает артефакты в папки.

| Режим | Что происходит | Когда использовать |
|---|---|---|
| `auto` | Оркестратор проходит этапы без вопросов, помечая допущения | Демо «что будет, если не вмешиваться» |
| `chat` | Оркестратор задаёт вопросы, ждёт ответов, уточняет | Human-in-the-loop |
| `hybrid` | Вопросы только на критичных развилках (контур, пользователи, платежи) | Рабочий режим |

## 2. Роли

| Роль | Зона ответственности | Ключевой артефакт |
|---|---|---|
| Product Manager | ценность, приоритет, риск-аппетит | business case, value-gate |
| Business Analyst | потребность → требования → критерии приёмки | бизнес-требования |
| System Analyst | требования → use cases, алгоритмы, спецификация | спецификация |
| Architect | архитектура, интеграции, наблюдаемость | architecture decision |
| Designer | пользовательские сценарии, визуализация | user flow / wireframe |
| Project Manager | декомпозиция, план, риски | roadmap, risk register |

Каждая роль = промпт + схема вывода (см. `prompts/roles/`).

Шаблоны — в `templates/`.

## 4. Правила

1. Факт без источника — не факт; помечать «допущение».
2. Если данных нет — задавать вопрос, а не выдумывать.
3. Отделять факты, допущения и гипотезы.
4. Проверять контур, платежи, интеграции, тип пользователей, домены/тарифы.
5. Каждый этап заканчивать чеклистом полноты.
6. Не переходить к системному анализу, пока не закрыт бизнес-анализ.

## 5. Контрольные точки (гейты)

| Гейт | Что проверяем | Владелец |
|---|---|---|
| BA-gate | problem statement, success metric, персоны, контур | BA + PM |
| SA-gate | use cases, функциональные / нефункциональные требования | SA |
| Spec-gate | полнота спецификации, трассируемость | SA + Architect |

Гейт отличается от отчёта: у него есть критерий, владелец и артефакт
прохождения (см. `books/common/knowledge/sdlc/gates.md`).
