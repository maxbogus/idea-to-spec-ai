# Упражнение 2 — валидация артефактов

**Время:** 15 минут. **Группы:** 3–4 человека.

## Задание

Дан набор артефактов из auto-прогона.

1. Найдите 3–5 галлюцинаций (факт / число / интеграция / персона).
2. Найдите немаркированные допущения.
3. Найдите пропущенные требования.
4. Заполните `templates/hallucination-log.md`.

## Вопросы для проверки

- Откуда взято это число?
- Это факт или допущение?
- Эта интеграция существует?
- Этот пользователь реален?
- Какое нефункциональное требование пропущено?

## Ожидаемый результат

Заполненный hallucination log + список исправлений в спеку.
