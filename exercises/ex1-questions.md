# Упражнение 1 — «плохой бриф → вопросы»

**Время:** 15 минут. **Группы:** 3–4 человека.

## Задание

Дан «плохой» бриф: «Хотим приложение, которое будет торговать этим».

1. Составьте 8–10 уточняющих вопросов.
2. Выпишите 5 пробелов.
3. Отметьте 3 вопроса, которые меняют следующий шаг сильнее всего.

## Критерии хорошего вопроса

- Меняет следующий шаг.
- Про контур, пользователей, платежи, интеграции, данные.
- Не «из любопытства».

## Примеры

- Плохо: «Какой у вас продукт?»
- Хорошо: «Что можно менять: тариф, подписку или только коммуникацию?»

## Ожидаемый результат

Список вопросов + пробелы + топ-3 вопроса.
